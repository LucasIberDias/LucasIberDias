<h2 align="center">Inteligência Artificial</h2>

### Assistente virtual de controle por voz (em desenvolvimento)

Projeto experimental de um assistente virtual para Windows, pensado para que o usuário interaja com o computador por voz e execute tarefas sem usar mouse e teclado. O foco é construir um **sistema próprio de reconhecimento de intenções**: entender o que a pessoa quis dizer e transformar isso em uma ação no computador, explorando conceitos de **processamento de linguagem natural (PLN)** e **aprendizado de máquina**.

<img src="https://skillicons.dev/icons?i=python" alt="Python"/> <img src="https://img.shields.io/badge/Scikit--Learn-F7931E?style=flat-square&logo=scikitlearn&logoColor=white" alt="Scikit-Learn"/>

**O que estou explorando**

- Captura de voz e conversão da fala em texto
- Classificação de intenções com aprendizado de máquina (Scikit-Learn)
- Pipeline de PLN: pré-processamento do texto, vetorização, treino e avaliação do modelo
- Mapeamento de cada intenção reconhecida para uma ação executada no computador

<h2 align="center">Projeto em destaque</h2>

### [LogSensei](https://github.com/LucasIberDias/LogSensei): gestão logística

Sistema web para apoiar a operação logística, do cadastro de clientes e produtos ao acompanhamento de ordens de carregamento e cargas. Nasceu de uma necessidade real de operação: o objetivo foi tirar o controle de cargas de planilhas e processos manuais. Interface em React consumindo uma API REST em Spring Boot, com autenticação JWT e perfis de acesso.

<img src="https://img.shields.io/badge/Java-21-ED8B00?style=flat-square&logo=openjdk&logoColor=white" alt="Java 21"/> <img src="https://img.shields.io/badge/Spring%20Boot-6DB33F?style=flat-square&logo=springboot&logoColor=white" alt="Spring Boot"/> <img src="https://img.shields.io/badge/React-61DAFB?style=flat-square&logo=react&logoColor=black" alt="React"/> <img src="https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white" alt="TypeScript"/> <img src="https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white" alt="PostgreSQL"/> <img src="https://img.shields.io/badge/JWT-000000?style=flat-square&logo=jsonwebtokens&logoColor=white" alt="JWT"/>

**O que o projeto faz**

- Autenticação com JWT e senhas protegidas com BCrypt
- Cadastro de clientes, produtos, veículos e usuários
- Criação de ordens de carregamento com itens, com cálculo automático do peso total
- Acompanhamento do ciclo de vida das cargas (`PENDENTE`, `ENTREGUE`, `CANCELADA`)
- Perfis de acesso (gerente, analista, filial e desenvolvedor)

**Decisões técnicas**

- Back-end em camadas (controller, service, repository, DTO), separando regra de negócio, acesso a dados e contrato da API
- Controle de acesso por perfil, para cada usuário ver só o que a sua função precisa
- Documentação com diagramas de arquitetura, modelo de domínio e fluxo operacional
